# Heart Disease Prediction & Analysis

A machine learning project built in Google Colab to analyze clinical data and predict the presence of heart disease using classification techniques.

---

## 📊 About the Project
This project performs Exploratory Data Analysis (EDA) and builds a machine learning model to help identify potential heart disease risks based on various patient health metrics.

---

## 📂 Repository Structure
- `heart_disease.ipynb`: The main Google Colab notebook containing data preprocessing, model training, and evaluation.
- `heart.csv`: The clinical dataset containing patient health parameters.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Environment:** Google Colab

---

## 🚀 How to Run
You can run this notebook directly in your browser using Google Colab:
1. Open the `heart_disease.ipynb` notebook.
2. Ensure the `heart.csv` dataset is linked properly or uploaded to your session environment.
3. Run the cells sequentially to reproduce the analysis.
